# نهاري مع ذكاء — برنامج حصص مركز ذكاء

موقع ثابت (بدون خادم) يعرض برنامج الحصص حسب المستوى الدراسي.

- **الموقع العام:** `index.html` — يقرأ الحصص من `data/schedule.json`.
- **لوحة الإدارة:** `admin/` — رابط خاص بالمشرفين. تعدّل الحصص وتنشرها بضغطة واحدة (تُسجَّل كتعديل في المستودع).

## تعديل الحصص
1. افتح رابط الإدارة: `…/admin/`.
2. أنشئ مفتاح وصول من GitHub (Fine-grained token) لهذا المستودع فقط، بصلاحية **Contents: Read and write**.
3. الصق المفتاح في صفحة الدخول. يُحفظ في متصفحك فقط.
4. أضف الحصص أو عدّلها، ثم اضغط **نشر التغييرات**. يظهر التحديث للزوار خلال دقائق.

## إضافة مشرف جديد
من المستودع على GitHub: **Settings → Collaborators → Add people**، ثم أدخل حسابه أو بريده. يقبل الدعوة، وينشئ مفتاحه الخاص ويدخل من صفحة الإدارة.

## تعديل يدوي
يمكن أيضًا تعديل `data/schedule.json` مباشرة. كل حصة: `p` الطور (`primary` / `middle` / `secondary`)، `y` السنة، `d` اليوم (0 السبت … 6 الجمعة)، `s` و`e` وقت البداية والنهاية، `sub` المادة، `room` القاعة، `note` ملاحظة.
الحصص التي يبدأ معرّفها بـ `demo-` تجريبية، وتظهر معها عبارة «حصص تجريبية» للزوار حتى تُحذف.
